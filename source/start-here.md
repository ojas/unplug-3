# Start here

**unplug-3** is a small documentation site. These starter pages give you a structure to build on; replace them as your own material takes shape.

## Find your way

The sidebar lists the main pages. On a small screen, use the menu button to open it. A page with several sections also has its own table of contents.

The search box looks through the site's text. Try searching for **callout** to find an example.

## Make it comfortable

Use the appearance button at the top of the page to switch between light, dark, and your system's preferred appearance.

## Add your first page

Start with a single subject: a note worth keeping, a process worth explaining, or a reference you return to often.

The [writing guide](writing-pages.md) covers the few steps needed to add it. The [examples page](examples.md) shows the available formatting.
